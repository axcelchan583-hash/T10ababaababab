# 给 ChatGPT Pro / Claude 网页版的深度评审 Prompt

请你以“经济学/管理学/创新研究领域审稿人”的身份评审下面这个研究设计。请不要只做润色，也不要默认支持该选题；请优先指出与既有文献重合、机制不清、识别不足、变量解释过度和投稿风险。

## 1. 研究问题

已有大量文献研究数字基础设施、宽带中国、智慧城市、大数据试验区等是否提升城市或企业创新总量。本文想换一个更窄的问题：

```text
城市算力基础设施提升是否扩大城市创新生态的进入边界？
```

也就是，不问“创新是否更多”，而问：

```text
原本没有出现在该城市专利系统中的申请人，是否更容易进入专利创新系统？
```

当前暂定标题：

```text
城市算力基础设施与创新进入边界扩展：
基于 IDC 服务覆盖和中国全量专利申请人数据的证据
```

英文题目备选：

```text
Does Computing Infrastructure Broaden the Extensive Margin of Urban Innovation?
Evidence from Licensed IDC Coverage in Chinese Cities
```

## 2. 核心变量

### X：城市算力基础设施

主解释变量：

```text
ln(1 + IDC_scope_city_stock_{c,t-1})
```

构造：

```text
基于 IDC 经营许可证业务覆盖范围中明确出现的城市，
按许可证颁发年份累计得到城市-年份 IDC 服务覆盖存量，
再滞后一期。
```

理论层面的 X 是城市算力基础设施，经验层面的测度是 IDC 经营许可覆盖强度。这样处理的理由是：IDC 业务覆盖了数据中心、数据存储、应用部署、云计算和互联网资源协作服务，是城市算力服务可得性的重要载体。

请注意：它不是机柜数、MW、FLOPS 或真实算力容量，只能谨慎解释为：

```text
城市 IDC 服务覆盖 / 算力服务可得性代理变量。
```

### 主 Y：新进入申请人份额

```text
new_applicant_share_{c,t}
= 本城市本年首次出现的申请人的专利数 / 本城市本年总专利数
```

“新进入”定义为：

```text
申请人首次出现在该城市专利申请人历史中。
```

不是企业新成立，也不是全国首次申请专利。

样本：

```text
2008-2023 年
291 个城市
4,647 个城市-年份
发明专利申请，按申请年份归年
城市聚类标准误
```

## 3. 想讲的机制

我想避免普通数字经济论文常见机制：

```text
信息流动、知识溢出、融资约束、劳动力错配、创业活跃度、企业创新效率。
```

当前想讲：

```text
创新进入固定成本下降机制。
```

机制链条：

```text
城市算力基础设施提升（以 IDC 服务覆盖强度测度）
-> 本地数据存储、云计算、应用部署和计算资源协作服务更可得
-> 数字化实验、数据处理、原型开发、技术验证的固定成本下降
-> 原本未进入城市专利系统的边缘主体更容易完成从想法/试验到正式专利申请的转换
-> 新进入申请人数量、新进入申请人专利数和新进入申请人份额上升
```

请重点评估：这个机制和已有数字基础设施/宽带中国/创业活跃度机制相比，是否真的不同？如果不够不同，应该怎么改？

## 5. 不能过度写的结论

不能写：

```text
IDC 稳健导致创新再集中。
```

因为 HHI/Top10 在加入政策控制和强固定效应后消失。

不能写：

```text
IDC 稳健提高企业/组织申请人的创新进入。
```

因为组织申请人口径不显著；企业层面只在高算力技术领域数量上有补充信号，份额不稳。

不能写：

```text
IDC 稳健提高高质量新进入份额。
```

因为授权/被引口径的份额变量方向为正但不显著，数量变量更稳。

不能写：

```text
已经完全排除其他政策干扰。
```

因为智慧城市、国家高新区、知识产权后续批次仍待补。
