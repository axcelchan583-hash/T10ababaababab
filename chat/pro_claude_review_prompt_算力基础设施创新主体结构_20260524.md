## 1. 当前题目

旧题已经放弃：

```text
城市数据 / 算力基础设施对企业创新韧性的影响
```

也不再写：

```text
城市算力基础设施削弱上市公司创新优势
```

当前更想写：

```text
城市算力基础设施建设与创新主体结构重塑：

```

或者更突出结果：

```text
进入扩容与头部集中并存：
城市算力基础设施如何重塑创新主体结构
```

核心研究问题：

```text
城市算力基础设施建设以后，城市内部创新增量由谁获得？
它是降低创新门槛、促进更多主体进入，还是强化头部主体的创新优势？
```

当前第一轮结果显示：两者可能同时发生。

## 2. 研究动机

已有大量文献已经证明数字基础设施、网络基础设施或算力基础设施会提高城市创新或企业创新总量。因此，如果我继续证明“基础设施促进创新”，贡献会很弱。

我现在想把问题从“创新总量效应”转到“创新分配效应”：

```text
基础设施建成后，城市创新生态内部的主体结构如何变化？
```

理论上有两种相反机制：

### 机制 A：进入扩容 / 创新扩散

算力基础设施、云服务和数据处理能力降低固定成本，使中小企业、新进入主体、非传统创新主体更容易开展研发、申请专利或进行数字技术创新。因此城市内活跃申请人和新进入申请人增加，Top 申请人份额下降，HHI 下降。

### 机制 B：头部吸收 / 创新再集中

算力基础设施与已有组织能力、研发队伍、数据资产、融资能力、政府项目连接和平台化能力互补。头部企业、高校、科研院所或大平台更能吸收算力红利。因此城市总创新增加的同时，Top 申请人份额和 HHI 也上升。

目前第一轮结果更像：

```text
进入扩容与头部集中并存。
```

即新进入申请人增加，但 HHI、Top5、Top10 也上升。

## 3. 数据与变量

### 3.1 X：城市算力基础设施

第一轮使用 IDC / 数据中心经营许可数据构造城市-年份代理变量：

```text
idc_stock
ln1p_idc_stock
ln1p_idc_stock_l1
idc_new
ln1p_idc_new
```

主 X 暂用：

```text
ln1p_idc_stock_l1
```

含义：截至上一年城市累计 IDC 许可 / 数据中心相关经营许可存量。

当前风险：

- IDC 许可证可能是企业经营许可或注册地，不一定完全等于实际机房、算力容量或服务节点所在地；
- 城市代码脏，第一轮按规范化城市名合并；
- 后续如果继续做，需要补更强 X，如机房地址、机柜数、服务器数、MW、智算中心、国家算力枢纽、数据中心集群等。

### 3.2 Y：城市创新主体结构

使用“中国全量专利数据库1985-2025.11”的分年份 CSV。已从 20GB RAR 中流式读取，不整包解压。

当前构造：

- 读取 2000-2024 年；
- 2000-2007 年作为新进入申请人预热期；
- 输出 2008-2024 年城市-年份-专利口径面板；
- 取第一申请人、第一申请人城市；
- 城市名去掉末尾“市”，过滤 `CN` 等异常值。

专利口径：

```text
all_pub       全部公开公告记录
inv_app_pub   发明申请公开
inv_grant_pub 发明授权公开
```

主 Y：

| 变量 | 含义 |
|---|---|
| `hhi` | 城市年度专利申请人份额 HHI |
| `top1_share` | 城市年度第一大申请人份额 |
| `top5_share` | Top5 申请人份额 |
| `top10_share` | Top10 申请人份额 |
| `effective_applicants` | 有效申请人数，`1 / HHI` |
| `active_applicants` | 当年活跃申请人数 |
| `new_applicants` | 当年新进入申请人数 |
| `new_applicant_share` | 新进入申请人的专利份额 |
| `total_patents` | 城市总专利数 |

面板规模：

- 18,329 行；
- 444 个城市 / 地区；
- 2008-2024 年；
- 三个专利口径；
- 合并 IDC 后，14,790 行能匹配 IDC 城市年面板，209 个城市曾经有 IDC 存量。
