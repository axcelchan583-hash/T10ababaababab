# Data Policy

本项目可以把“直接支撑复核的中小型处理后面板”放进 git，但不建议把全部数据目录或原始专利库放进 git。

## 当前体量

截至 2026-05-28：

- 项目目录约 602M；
- `data/processed` 本地约 548M；
- git 已追踪的 data 文件约 154M；
- 当前最大已追踪文件是 `data/processed/overall_tech_entry_ddd_robustness_panel_2008_2023.csv`，约 44M。

这些已追踪文件均低于 GitHub 单文件 100M 的硬限制，但仓库已经不算轻。

## 建议放进 git 的内容

- 研究设计、memo、outline；
- 构造脚本和回归脚本；
- 小型外部 proxy，例如 IDC 许可城市年面板；
- 可直接复核主表的关键处理后 CSV；
- 回归结果 CSV / JSON。

## 不建议放进 git 的内容

- 原始全量专利数据库；
- 第三方付费数据库原始文件；
- `.dta`、`.xlsx`、`.rar`、`.zip`；
- 可由脚本重复生成的大型中间面板；
- 与当前主线无关的历史试跑面板。

## 如果继续扩容

若后续需要公开复现，建议：

1. git 中保留脚本、说明、变量字典和小型结果表；
2. 大型处理后数据用 Git LFS、OSF、百度网盘、Zenodo 或私有云盘；
3. 在 `data/raw/README.md` 和论文附录中列明原始数据来源、不可公开原因、生成脚本和哈希校验。
