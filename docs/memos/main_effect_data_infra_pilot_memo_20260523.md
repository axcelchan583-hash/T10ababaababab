# 城市数据基础设施与企业创新韧性：主效应试跑备忘

## X 口径

按会计研究截图口径构造：

```text
Data_infra = Treat x Post2016
```

其中 `Post2016 = 1[year >= 2016]`。

`Treat` 映射为国家大数据综合试验区覆盖地区：

- 贵州省
- 河南省
- 内蒙古自治区
- 重庆市
- 上海市
- 京津冀：北京市、天津市、河北省
- 珠三角九市：广州市、深圳市、珠海市、佛山市、惠州市、东莞市、中山市、江门市、肇庆市
- 沈阳市

广东省没有全省处理，只处理珠三角九市。

## Y 口径

使用已由 Stata MCP 复现的公开企业创新韧性数据，年份为 2000-2024。

主 Y：

- `企业创新韧性1`：企业发明专利授权变化相对城市发明专利授权增长基准的超额表现。

稳健性 Y：

- `企业创新韧性2`：企业专利申请韧性。
- `企业创新韧性3`：企业专利授权韧性。
- `企业创新韧性4`：行业基准专利申请韧性，不建议作为主 Y。

## 试跑模型

```text
InnovationResilience_it = beta Data_infra_ct + FirmFE + YearFE + error_it
```

标准误按城市聚类。主样本为 2008-2024 年，排除 ST 和金融业。

## 判断

第一版结果不支持“城市数据基础设施稳定提升企业一般创新韧性”。

更具体地说：

- 主 Y `企业创新韧性1` 没有正向结果。
- `企业创新韧性3` 原始值为弱正向，但缩尾后不显著，说明受极端值影响较大。
- `企业创新韧性4` 有弱正向，但该变量自身构造解释力较差，不适合作为主结论。

当前结果适合当作数据诊断，不适合直接写成论文主发现。
