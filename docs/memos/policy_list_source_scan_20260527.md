## 2. 可直接进入下一步的名单

### 2.1 宽带中国示范城市

可用性：高。

来源：

- 工信部/发改委 2014 年公告；
- 工信部 2015 年名单 PDF；
- 工信部/发改委 2016 年公告，中央网信办转载。

处理：

- 2014 年直辖市和其他城市直接入表；
- 2014 年 `长株潭城市群` 扩展为长沙、株洲、湘潭；
- 2015 年重庆江津区、荣昌区先映射到重庆；
- 2016 年九龙坡区、北碚区先映射到重庆；
- `福州市（含平潭）` 先映射为福州，平潭不单独进入地级市主样本。

判断：这是最应该先进 horse-race 的政策。

### 2.2 创新型城市

可用性：中高。

来源：

- 科技部/发改委 2016 年《创新型城市试点建设名单》PDF；
- 科技部/发改委 2018 年支持新一批城市开展创新型城市建设的函。

处理：

- 2016 年名单作为一个存量批次；
- 2018 年新增城市按 2018 年进入；
- 海淀区、滨海新区、杨浦区、沙坪坝区分别映射到北京、天津、上海、重庆。

风险：

- 2016 年名单里有一些城市其实在更早年份已开始试点。若把它们统一设为 2016，时间会偏晚。
- 第一轮 horse-race 可以先放；正式稿最好补早期批次。

### 2.3 大数据综合试验区

可用性：中。

来源显示：

- 贵州为第一个国家大数据综合试验区；
- 2016 年又批复京津冀、珠江三角洲、上海、河南、重庆、沈阳、内蒙古七个地方和区域。

处理建议：

- 上海、重庆、沈阳可作为城市 dummy；
- 贵州、河南、内蒙古是省级处理，`province × year FE` 下会被吸收；
- 京津冀、珠三角是区域处理，需单独定义 broad coding。

风险：

- 不能无脑把省级政策解释成城市层面政策。
- 在强规格中，这个变量主要用于说明政策叠加，不一定能估出独立系数。

### 2.4 国家知识产权示范城市

可用性：中。

已整理：

- 2012 首批 23 个城市；
- 2013 第二批 18 个城市。

待补：

- 2015、2016、2018、2019 等后续批次；
- 或使用国家知识产权局“原国家知识产权示范城市名单”做存量 dummy。

风险：

- 这个政策直接影响专利行为，是 horse-race 中最不能漏的创新政策之一。

## 3. 已定位但未完全抽取的名单

### 3.1 国家智慧城市试点

状态：来源已定位，但三批名单还没完全结构化。

已找到：

- 2014 年国家智慧城市试点名单页面，含 84 个新增试点和 13 个扩大范围试点；
- 2012/2013 批次需要继续抽，或直接下载第三方 DID 表。

判断：

```text
智慧城市是必须补的政策控制。
如果时间紧，建议直接下载一份现成 DID 表，再用官方源抽样核验。
```

### 3.2 国家高新区

状态：官方源已定位，但本地访问火炬中心官网不稳定。

建议：

- 不做简单 dummy；
- 做城市-年份 `national_hightech_zone_count`；
- 字段需要高新区名称、批准年月、所属地级市。

判断：

```text
高新区是创新政策/产业平台控制，必须补，但工程量比宽带中国更大。
```
