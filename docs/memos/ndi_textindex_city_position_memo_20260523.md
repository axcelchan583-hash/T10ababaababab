# 新型数字基础设施词频指数 X：第一轮试跑

日期：2026-05-23

## 1. X 的来源和含义

数据来源：

`/Users/mac/computerscience/第三方资料/01_数据资源/数字基础设施/地级市新型数字基础设施水平数据（2003-2024年）/数据结果/原始数据.xlsx`

这套数据来自城市政府工作报告关键词词频，不是硬件基础设施存量。因此它更准确的含义是：

> 城市政府对新型数字基础设施建设的政策关注度。

原始表包含 52 个关键词列，例如：

- 5G
- 信息基础设施
- 大数据
- 数字基础设施
- 云计算
- 互联网
- 物联网
- 人工智能
- 数据中心
- 智慧城市
- 电子政务
- 软件

已构造三种 X：

- `ln1p_ndi_kw_per10k`：每万字关键词总词频，取 `ln(1+x)`。
- `ndi_entropy_mm`：52 个关键词频率经正向化、标准化后，用熵值法合成的指数。
- `ndi_pca1_mm`：52 个关键词频率经 `log(1+x)` 后提取第一主成分，并标准化到 0-1。

同时构造滞后一期：

- `ln1p_ndi_kw_per10k_l1`
- `ndi_entropy_mm_l1`
- `ndi_pca1_mm_l1`

合并后的面板：

`outputs/city_innovation_position_with_ndi_textindex_2003_2024.dta`

匹配情况：

- 原始词频数据：5760 行，286 个城市，2003-2024 年。
- 与城市创新相对地位面板匹配：5760 个城市-年份。
- 未匹配：1690 个城市-年份，主要是 2000-2002 和少数城市缺政府报告词频数据。

## 2. 回归设定

城市固定效应 + 年份固定效应，标准误按城市聚类。

核心结果文件：

`outputs/ndi_textindex_city_position_results_20260523.csv`

核心 Y：

- 城市发明授权总量。
- A 股上市公司发明授权合计。
- 非 A 股近似发明授权。
- 非 A 股相对上市公司：`ln(non-A股近似) - ln(A股上市公司合计)`。
- A 股上市公司发明授权份额。

## 4. 当前判断

这个“翻转变量/统一取一个度数”的词频综合指数没有救出主线。

更具体地说：

1. 每万字关键词总词频有一个表面上对我们有利的结果：2012-2022 中非 A 股相对上市公司为正。
2. 但这个结果伴随着城市整体创新、上市公司创新和非 A 股近似创新全部显著为负，理论上很难解释为基础设施赋能。
3. 熵值法指数和 PCA 指数没有稳定支持“上市公司份额下降”。
4. 因此，这个 X 如果用作主解释变量，含义会变成“政府工作报告数字基础设施注意力”，识别和理论都比 IDC 更软。

## 5. 结论

目前不建议把这个词频型新型数字基础设施指数作为主 X。

它可以留作补充稳健性或“政策关注度”替代度量，但不能支撑：

> 城市数字/算力基础设施削弱上市公司创新相对优势。

如果还要继续这条线，下一步不是继续换 X，而是换 Y：

- 上市公司在城市高价值专利中的份额；
- 上市公司 Top1/Top5 创新集中度；
- 上市公司城市创新排名；
- 20G 专利微观数据拆分出的非上市企业/高校/科研院所增长。
