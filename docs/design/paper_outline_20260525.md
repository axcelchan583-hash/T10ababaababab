# 论文大纲：城市算力基础设施与创新进入边界扩展

日期：2026-05-25

## 题目

推荐：

```text
城市算力基础设施与创新进入边界扩展：
来自中国全量专利申请人数据的证据
```

备选：

```text
算力基础设施是否降低城市创新进入门槛？
基于 IDC 服务覆盖和中国全量专利申请人数据的证据
```

## 摘要思路

已有研究主要关注数字基础设施是否提高城市或企业创新总量。本文转向城市内部创新参与边界，考察城市算力基础设施提升是否带来更多新进入专利申请人。经验上，本文使用 IDC 经营许可证业务覆盖范围构造城市 IDC 服务覆盖强度，作为城市算力基础设施和算力服务可得性的代理变量，并基于中国全量专利申请人数据构造 2008-2023 年城市-年份面板。结果显示，IDC 覆盖强度提升后，新进入申请人专利份额稳健上升。分解结果表明，这一变化来自新进入申请人数和新进入申请人专利数同步上升，而不是既有主体专利下降造成的机械份额变化。围绕 `scope >= 2` 的现代 DID 复核进一步显示，Borusyak-Jaravel-Spiess 和 Callaway-Sant'Anna 估计均支持事件后 1-4 年新进入申请人份额显著上升，处理前三期没有明显预趋势。技术领域 DDD 显示，高算力依赖领域的新进入申请人数、新进入专利数和新进入份额相对上升，但低算力领域也存在正向扩容，因此本文将机制解释为“普遍进入扩容 + 高算力领域额外增强”。进一步分析显示，组织申请人与发明授权口径尚未稳健打赢，不能解释为企业或高质量创新进入已经确定扩张。本文的核心贡献在于将数字/算力基础设施研究从创新总量效应推进到创新参与边界变化，同时说明进入扩展并不等同于企业进入或高质量创新进入。

## 1. 引言

### 1.1 研究背景

- 数字基础设施、数据中心、云计算和算力基础设施成为城市创新政策的重要组成部分。
- 既有研究已经大量证明宽带、数字基础设施、大数据试验区、IDC 等促进企业或城市创新总量。
- 但创新总量增加之后，城市内部由谁参与、谁进入、谁获得新增创新机会，仍不清楚。

### 1.2 研究问题

主问题：

```text
城市算力基础设施提升是否扩大城市创新进入边界？
```

补充问题：

```text
这种进入扩展是否同时伴随城市创新产出向头部集中？
如果有，是否来自企业、高校科研或个人主体？
```

### 1.3 本文做法

- 使用全量专利申请人数据构造城市-年份创新主体结构变量。
- 使用 IDC 经营许可业务覆盖范围构造城市 IDC 服务覆盖强度，并将其作为城市算力基础设施的经验测度。
- 用连续处理强度固定效应模型、阈值事件研究、样本稳健性和类型分解检验。

### 1.4 核心发现

主发现：

- IDC 覆盖强度提升后，新进入申请人专利份额上升。
- 新进入申请人数和新进入申请人专利数同步上升，既有主体专利没有显著下降，排除单纯分母效应。
- 事件研究和现代 DID 支持进入边界扩展：`scope >= 2` 下事件前趋势干净，BJS 与 CSDID 均显示事件后 +1 至 +4 年新进入申请人份额上升。
- 整体申请人技术领域 DDD 显示，高算力依赖领域的新进入申请人数、新进入专利数和新进入份额相对上升。

补充发现：

- 常规固定效应下 HHI/Top10 上升，中腰部既有主体份额下降。
- 但头部再集中不稳，不能作为强因果主结论。
- 类型分解不支持企业/高校/上市公司头部吸收能力稳健增强。
- 新进入类型拆分显示，当前进入扩展更多来自个人申请人；企业、知识机构和组织申请人暂未稳健打赢。
- 发明申请公开口径支持主结果，发明授权口径方向为正但不显著。
- 企业层面的城市-年份新进入份额不稳；企业技术领域 DDD 显示高算力领域企业新进入数量相对上升、份额没有上升，因此企业结果只作为补充。

### 1.5 贡献

1. 从“数字基础设施是否促进创新总量”转向“创新参与边界是否扩展”。
2. 使用全量专利申请人微观数据构造城市内部主体结构指标。
3. 将城市算力基础设施的理论对象与 IDC 经营许可覆盖强度的经验测度区分开，并区分覆盖范围和注册地址。
4. 识别进入扩容与头部集中之间的差异：进入扩容较稳，头部再集中证据有限。

## 2. 文献综述

### 2.1 数字基础设施与创新总量

应覆盖：

- 宽带中国与城市创新；
- 宽带/互联网与企业创新；
- 大数据综合试验区与创新；
- IDC/算力基础设施与企业数字创新。

写法：

```text
这些研究回答“是否更多创新”，本文回答“谁进入创新”。
```

### 2.2 创新集中、头部企业和知识扩散

应覆盖：

- 创新活动向头部企业/头部城市集中；
- 数字技术与地理集中；
- superstar firms / declining business dynamism；
- absorptive capacity 和 GPT。

写法：

```text
这些研究强调数字技术可能强化集中，但本文发现至少在当前数据中，
进入边界扩展比头部再集中更稳。
```

### 2.3 专利申请人结构与创新生态

应覆盖：

- 专利申请人 HHI；
- Top applicant share；
- new applicant / entrant；
- 中国专利质量和补贴问题。

写法：

```text
本文将申请人进入作为城市创新生态变化的核心指标。
```

## 3. 理论机制与研究假说

### 3.1 进入成本下降

城市算力基础设施降低：

- 计算资源获取成本；
- 数据处理和实验成本；
- 云服务和研发工具使用门槛；
- 小主体进入创新活动的固定成本。

假说 1：

```text
城市算力基础设施提升会提高新进入申请人数量和新进入申请人专利份额。
```

### 3.2 头部吸收能力：竞争性机制

算力基础设施也可能与既有组织能力互补：

- 研发团队；
- 数据资产；
- 应用场景；
- 融资能力；
- 政府项目承接能力。

假说 2a：

```text
如果吸收能力机制占主导，IDC 扩张会提高 HHI、Top share 和基期 Top 份额。
```

假说 2b：

```text
如果进入扩容占主导，IDC 扩张会降低或不提高 HHI/Top share。
```

当前实证倾向：

```text
进入扩容更稳；头部吸收能力机制没有得到稳健支持。
```

### 3.3 主体类型

预测：

- 若企业吸收能力机制成立，企业 Top 份额或新进入企业应上升；
- 若科研基础设施机制成立，高校/科研 Top 份额或新进入高校科研应上升；
- 若低门槛申请机制成立，个人或低质量专利进入可能上升。

### 4.3 城市算力基础设施变量

主 X：

```text
ln(1 + IDC_scope_city_stock_{c,t-1})
```

解释：

- 理论对象是城市算力基础设施；
- 经验测度是 IDC 经营许可证业务覆盖范围；
- 按城市-年份累计；
- 滞后一期。

写作边界：

```text
IDC_scope_city_stock 表示 IDC 服务覆盖强度 / 算力服务可得性代理，
不能直接等同于真实机柜数、MW、FLOPS 或算力价格下降。
```

稳健性 X：

- 注册地口径；
- combined 口径；
- 近五年 stock；
- 当年新增；
- 省份口径。

### 4.4 控制和固定效应

主规格优先用固定效应吸收：

- 城市固定效应；

- 省份 × 年份固定效应；
- 基期创新能力 × 年份固定效应；
- 基期集中度 × 年份固定效应；
- 城市趋势。

## 5. 识别策略

### 5.1 连续处理强度固定效应模型

写模型：

```text
Y_{c,t} = β ln(1 + IDC_scope_city_stock_{c,t-1})
        + μ_c
        + Province × Year FE
        + BaselineCapacity × Year FE
        + ε_{c,t}
```

解释识别：

- 利用同一城市 IDC 覆盖强度随时间变化；
- 与同省同年其他城市比较；
- 控制基期创新能力和基期集中度的差异趋势。

### 5.2 事件研究

核心事件定义：

```text
IDC_scope_stock 首次达到 >= 2
```

事件窗口：

```text
<= -4, -3, -2, -1, 0, +1, +2, +3, >= +4
```

`-1` 为基准期。

当前最重要结果：

```text
pre-trend p = 0.765
+1 年 new_applicant_share p = 0.033
+2 年 new_applicant_share p = 0.084
```

现代 DID 复核：

```text
BJS：前趋势联合检验 p = 0.762，+1 至 +4 年 new_applicant_share 均显著为正。
CSDID：+1 至 +4 年 new_applicant_share 均显著为正。
```

### 5.3 识别边界

必须承认：

- 不是完美自然实验；
- IDC 布局可能内生；
- 当前证据是准因果证据，不应过度宣称；
- 需要在后续用更强 X、政策冲击或 IV 补强。

## 7. 结构性补充：集中度与中腰部份额

放在主结果之后，作为“不是单纯民主化”的补充。

结果口径：

- HHI/Top10 在普通省份×年份 FE 下为正；
- 基期 Top 上升、中腰部下降有信号；
- 强固定效应和事件研究下不稳。

写法：

```text
城市创新进入边界扩展并不必然意味着创新产出完全分散。
但现阶段不能把头部再集中作为强因果结论。
```

## 8. 机制检验

最优先机制：

### 8.1 新进入者类型

已完成第一轮构造：

- 新进入企业申请人；
- 新进入高校/科研/医院等知识机构；
- 新进入个人申请人；
- 新进入组织申请人。

当前结果：

- 企业、知识机构和组织申请人的新进入份额暂不显著；
- 个人新进入份额和个人新进入数量显著上升；
- 因此主文不能写“IDC 促进企业创新进入”，只能写“整体创新进入边界扩展”。

当前第一轮技术领域与企业结果：

- 整体申请人技术领域 DDD 已打赢：高算力领域的新进入申请人数、新进入专利数和新进入份额相对上升；
- 低算力领域单独回归仍为正，因此不能写“只影响高算力领域”，应写“普遍扩容 + 高算力额外增强”；
- 城市-年份企业 Y 不能替代主 Y；
- 企业技术领域 DDD 可作为补充：高算力领域的企业新进入数量增加，但份额不升；
- 这更支持“进入数量扩张 + 既有企业吸收更快”，而不是“企业新进入份额扩张”。

### 8.2 创新质量

已做快速口径：

- 发明申请公开：支持主结果；
- 全部专利公开：方向一致但较弱；
- 发明授权公开：方向为正但不显著。

下一步要做：

- 发明授权；
- 授权后维持年限；
- 被引；
- 同族；
- 高价值专利。

目标：

```text
排除新进入只是低质量、补贴驱动或个人申请噪声。
```

### 8.3 成本下降机制

可尝试：

- 云服务节点；
- 数据中心机房容量；
- 机柜数/MW；
- 智算中心；
- 城市数字服务供给。

## 9. 异质性

推荐异质性：

1. 技术领域异质性：高算力依赖技术领域 vs 其他领域；
2. 主体类型异质性：企业、高校/科研、个人、组织申请人；
3. 基期创新能力高 vs 低；
4. 基期申请人集中度高 vs 低；
5. 高专利量城市 vs 低专利量城市；
6. 企业主导城市 vs 高校科研主导城市；
7. 数字基础强 vs 弱；
8. 东中西部或算力枢纽/非枢纽。

不建议主文堆太多异质性。主文保留 2-3 个最有理论含义的。

当前建议主文优先放：

```text
整体申请人技术领域 DDD + 主体类型拆分 + 基期创新能力异质性
```

其中企业技术领域 DDD 的定位是：

```text
高算力领域企业新进入数量增加，但份额没有增加。
这不是主结论，而是说明“进入扩张”不等于“新企业拿到更高份额”。
```

- 剔除大城市；
- 高专利量样本；
- 替代 X；
- 事件研究；
- BJS / CSDID 现代 DID；
- 时间安慰剂；
- 组织申请人口径；

附录可放：

- 注册地/combined；
- 当年新增 IDC；

## 11. 讨论

重点讨论：

- 为什么“进入扩容”比“再集中”更稳；
- 为什么不能简单写“创新民主化”；
- 为什么不能简单写“头部企业吸收能力”；
- IDC 许可数据的测量含义和局限；
- 中国专利质量问题。

## 12. 结论

结论应保守：

```text
城市算力基础设施提升与城市创新进入边界扩展密切相关，
并在事件研究中呈现较清晰的动态证据。
```

不要写：

```text
IDC 明确导致创新再集中；
IDC 明确强化企业/高校头部创新优势。
```
