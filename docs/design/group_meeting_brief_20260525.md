# 组会简报：城市算力基础设施与创新进入边界扩展

日期：2026-05-25

## 1. 现在这个题想问什么

已有文献已经比较充分地证明了数字基础设施、网络基础设施或算力基础设施会提高城市或企业创新总量。这个项目不再重复“是否促进创新”，而是进一步问：

```text
城市算力基础设施提升后，城市创新生态是否吸纳了更多原本没有参与专利申请的主体？
```

更适合的题目是：

```text
城市算力基础设施与创新进入边界扩展：
来自中国全量专利申请人数据的证据
```

## 2. 当前主 X 和主 Y

主 X：

```text
ln(1 + IDC_scope_city_stock_{c,t-1})
```

含义：

```text
基于 IDC/电信业务经营许可数据，
只使用许可证业务覆盖范围中明确出现的城市，
按许可证颁发年份累计得到城市-年份 IDC 覆盖强度。
```

这个变量更准确地说是：

```text
IDC 经营许可覆盖强度 / 城市 IDC 服务覆盖强度
```

理论对象可以写城市算力基础设施，但不应把该变量直接说成真实算力容量、机柜数或 MW。

主 Y：

```text
new_applicant_share_{c,t}
```

定义：

```text
本城市本年首次出现的申请人的专利数 / 本城市本年总专利数
```

配套 Y：

```text
ln(1 + new_applicants_{c,t})
```

这里的新进入是“首次出现在该城市专利申请人历史中”，不是企业新成立，也不是全国首次申请专利。

## 3. 当前最稳结果

主回归样本：

```text
2008-2023 年
291 个城市
4,647 个城市-年份观测
```

结果：

- `new_applicant_share` 在城市+年份 FE、省份×年份 FE、强固定效应、城市趋势中均为正；
- `ln1p_new_applicants` 在强固定效应和城市趋势中为正；
- 剔除大城市和高专利量样本后，新进入份额仍较稳；
- 尾部合并事件研究中，`scope >= 2` 的前趋势较干净，事件后 1-2 年新进入申请人份额上升；
- 现代 DID 复核中，BJS 与 CSDID 均显示事件后 1-4 年新进入申请人份额上升。

事件研究最能看的口径：

```text
IDC_scope_stock 第一次达到 >= 2
处理城市：66 个
总城市：275 个
强固定效应下前趋势联合检验 p = 0.765
事件后 +1 年 new_applicant_share 上升，p = 0.033
事件后 +2 年 new_applicant_share 上升，p = 0.084
```

现代 DID 复核：

```text
BJS：处理前三期联合检验 p = 0.762，事件后 +1 至 +4 年均显著为正。
CSDID：事件后 +1 至 +4 年均显著为正。
```

因此当前可以讲：

```text
城市算力基础设施提升后，城市创新进入边界扩大。
实证上，这一提升由 IDC 经营许可覆盖强度刻画。
```

## 4. 不能强讲什么

当前不能强讲：

```text
IDC 明确导致城市创新头部再集中；
IDC 强化企业/高校/上市公司头部吸收能力；
IDC 稳健提高企业新进入份额。
```

原因：

- HHI、Top10、基期 Top 份额在常规省份×年份 FE 下有正信号，但加入基期能力/集中度×年份 FE 后明显变弱；
- 事件研究中 HHI/Top10/base_top 的动态不稳定；
- Top 类型拆分不支持企业、高校/科研或上市公司头部份额稳健上升；
- 企业城市-年份口径的新进入份额不显著。

所以头部集中、中腰部挤压、企业吸收能力只能作为结构性补充或讨论，不能作为主因果结论。

## 5. 机制和异质性已经补到哪里

本轮已经把主结果拆成分子、分母和主体类型。强固定效应规格下：

| Y | 系数 | p 值 | 含义 |
|---|---:|---:|---|
| `new_applicant_share` | 0.0227 | 0.046 | 新进入份额上升 |
| `ln1p_new_applicants` | 0.1182 | 0.008 | 新进入申请人数上升 |
| `ln_new_patents` | 0.1153 | 0.028 | 新进入申请人专利数上升 |
| `ln1p_total_patents` | 0.0853 | 0.061 | 城市总专利边际上升 |
| `ln_incumbent_patents` | 0.0328 | 0.486 | 既有主体专利没有显著下降 |

因此当前可以防守：

```text
新进入份额上升不是简单分母效应；
IDC 覆盖提升后，新进入申请人数和新进入申请人专利数同步上升。
```

但主体类型拆分也暴露了风险：

- 企业新进入份额、企业新进入数量、企业新进入专利数暂不显著；
- 高校/科研等知识机构暂不显著；
- 个人新进入份额和个人新进入数量显著上升；
- 组织申请人口径暂不显著。

发明授权口径方向为正，但显著性不足。因此组会要诚实讲：

```text
主线可以先写“创新进入边界扩展”，
但不能写“企业创新进入”或“高质量创新进入”已经被证实。
下一步必须补高价值/授权/维持年限等质量口径。
```

## 6. 技术领域和企业层面应该怎么放

企业层面适合做异质性/补充，不适合换成主 Y。

城市-年份企业 Y：

- `firm_new_share_total` 不显著；
- `ln1p_new_firm_patents` 不显著；
- `ln1p_new_firm_applicants` 只在高专利量城市中边际为正；
- 企业口径事件研究不清楚。

进一步做了整体申请人与企业两套城市 × 技术领域 × 年份 DDD：

```text
Y_{c,k,t} = beta * ln(1 + IDC_scope_stock_{c,t-1}) × HighCompute_k
          + city × year FE
          + city × HighCompute FE
          + HighCompute × year FE
          + error
```

结果：

- 整体申请人口径中，高算力技术领域的新进入申请人数、新进入专利数和新进入份额均相对上升；
- 低算力领域单独回归也为正，因此更准确说法是“普遍扩容 + 高算力额外增强”；
- 高算力技术领域的企业新进入数量相对上升；
- 高算力技术领域的新进入企业专利数相对上升；
- 但新进入企业份额没有上升，连续强度 DDD 中反而为负；
- 既有企业、企业总专利和企业活跃申请人数增长更快；
- 事件 DDD 有处理后数量正信号，但前趋势不干净。

组会中建议这样讲：

```text
整体申请人技术领域 DDD 可以作为主文异质性/机制补充：
IDC 覆盖提升后，高算力领域的新进入边界扩张更明显。
企业层面只作为附加证据：高算力领域有更多企业进入，
但份额没有向新进入企业倾斜，既有企业增长更快。
```

## 7. 建议的论文结构

主线：

```text
城市算力基础设施提升（以 IDC 服务覆盖强度测度） -> 整体创新进入边界扩大
```

结构性补充：

```text
常规固定效应下有头部集中和中腰部挤压迹象，
但不作为强因果主结论。
```

异质性/补充：

```text
整体申请人高算力领域的新进入数量和份额扩张更明显；
企业高算力领域的新进入数量上升，但企业新进入份额没有扩张。
```

下一步最该补：

1. 高价值或授权口径：排除低质量个人申请和补贴型申请；
2. 政策 horse-race：宽带中国、智慧城市、大数据综合试验区、创新型城市、高新区、知识产权示范城市；
3. 技术领域更细拆分：不仅二分高算力/其他，也可以做 IPC/CPC 组；
4. 现代 DID 继续扩展到质量口径和更细阈值；
5. X 补强：机房地址、机柜数/MW、智算中心、国家算力节点。

## 8. 希望老师判断的问题

1. 是否认可把主线收窄为“城市算力基础设施是否扩大城市创新进入边界”，并用 IDC 服务覆盖强度作为第一版测度？
2. `new_applicant_share` 能否作为主 Y？如果担心个人/低质量专利，最该优先做哪种质量筛选？
3. 整体申请人高算力领域 DDD 是否可以放主文机制/异质性，企业 DDD 是否只放附录？
4. 目前的 IDC 经营许可覆盖范围变量是否足够作为第一版 X？还必须补什么 X 才能冲更高期刊？
5. 头部集中和中腰部挤压是否值得保留为第二层结构结果，还是干脆降到附录？
