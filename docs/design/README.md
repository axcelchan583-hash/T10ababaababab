日期：2026-05-25

本目录用于整理当前可供外部评审的研究设计和论文大纲。当前版本已经放弃“企业创新韧性”和“上市公司创新优势削弱”的旧叙事，主线收窄为：

```text
城市算力基础设施提升是否扩大城市创新进入边界？
```

统一表述口径：

```text
理论对象：城市算力基础设施；
经验测度：IDC 经营许可覆盖强度 / IDC 服务覆盖强度；
变量名称：ln(1 + IDC_scope_city_stock_{c,t-1})。
```

## 当前判断

可以作为主线写：

```text
城市算力基础设施提升扩大城市创新生态的进入边界，
表现为新进入申请人份额上升。
```

暂时不能作为主因果结论写：

```text
IDC 明确导致城市创新头部再集中；
IDC 强化企业/高校/上市公司头部吸收能力。
IDC 稳健提高企业新进入份额。
```

原因是 HHI、Top10、基期 Top 和组织申请人口径结果对强固定效应、事件研究和类型分解较敏感。

## 机制与异质性补充

2026-05-25 已完成新进入机制拆分、主体类型拆分、城市基础异质性和快速质量稳健性。

结论：

- 主结果不是简单分母效应：新进入申请人数和新进入申请人专利数同步上升，既有主体专利没有显著下降；
- 新进入类型中，当前最稳的是个人申请人进入，企业/知识机构/组织申请人口径暂不显著；
- 发明申请公开口径支持主结果，发明授权口径方向为正但不显著；
- 基期创新能力、集中度和主体结构异质性暂不清楚。

## AJG3 升级检验第一轮

2026-05-25 已补一轮最小升级检验：

- `scope >= 2` 的现代 DID 复核：Borusyak-Jaravel-Spiess 和 Callaway-Sant'Anna 都显示事件后 1-4 年 `new_applicant_share` 显著上升，处理前三期不显著；
- 整体申请人城市 × 高算力技术领域 × 年份 DDD：高算力领域的新进入申请人数、新进入专利数和新进入份额相对上升；
- 时间安慰剂：未来 3 年、5 年 IDC 覆盖对 `new_applicant_share`、`ln1p_new_applicants`、`ln1p_new_patents` 均不显著；
- 组织申请人与发明授权口径仍不稳，不能把主结论升级为“企业/组织/高质量创新进入”。

当前判断：

```text

但机制口径要谨慎：高算力领域额外更强，组织/企业进入和授权质量尚未打赢。
```

## 2026-05-28 补充：Y 清洗与 X 内部验证

已按外部审稿意见补一轮防守检验：

- 主申请年份口径的新进入申请人预热期从 2000 年前移到 1985 年；
- 主结果方向基本不变，说明 `new_applicant_share` 不是由 2000 年左截断机械制造；
- 新进入申请人数和新进入申请人专利数同步上升，支持“进入边界扩展”而非单纯分母变化；
- 申请人类型拆分显示，当前强规格下主要来自个人申请人，企业/组织进入不稳；
- IDC 许可证拆分显示，云/计算相关许可对新进入边界的解释力强于非云/计算许可；

## 2026-05-28 追加：主效应改为城市×技术领域 DDD

为降低城市年层面“城市对城市”比较的识别压力，已用 1985 预热期重建整体申请人城市×技术领域×年份 DDD 面板。

新主识别：

```text
Y_cft = beta ln(1 + IDC_scope_stock_{c,t-1}) × HighCompute_f
      + city × year FE
      + city × HighCompute FE
      + HighCompute × year FE
      + error_cft
```

识别含义：

```text
同一个城市同一年，高算力依赖技术领域的新进入是否相对低算力领域更多。
```

1985 预热期重跑后，并按“显式常数项 + drop-first dummy”的标准固定效应实现复核：

- 新进入申请人数：系数 0.2184，p < 0.001；
- 新进入申请人专利数：系数 0.2560，p < 0.001；
- 新进入申请人份额：系数 0.0310，p = 0.0270；
- 限制高专利量城市后，数量型新进入结果仍显著。

当前设计调整为：

```text
城市年主效应作为背景事实；
城市×技术领域 DDD 作为主效应/主识别。
```

## 2026-05-28 晚追加：PPML 函数形式压力测试

按照外部评审意见，已对城市×技术领域 DDD 的数量型 Y 补高维固定效应 PPML：

```text
E[Y_cft] = exp(
    beta ln(1 + IDC_scope_stock_{c,t-1}) × HighCompute_f
    + city × year FE
    + city × HighCompute FE
    + HighCompute × year FE
)
```

结果与 `ln1p` OLS 方向相反：

- `broad` 定义下，新进入申请人数 PPML 系数为 -0.1544，p < 0.001；
- 新进入专利数 PPML 系数为 -0.1270，p = 0.0245；
- 替换 HighCompute 定义、剔除个人、剔除 one-shot 后，方向仍主要为负。

因此当前设计应降级：

```text
城市×技术领域 DDD 不能直接作为最硬主识别；
它只能作为机制探索或函数形式压力测试。
```

## 企业层面补充试验

2026-05-25 已完成企业申请人口径和城市 × 技术领域 × 年份 DDD 第一轮。

结论：

- 城市-年份企业 Y 不适合替代主 Y；

## 组会建议口径

建议组会中不要把企业层面改成主线，而是按以下顺序讲：

1. 主结果：`IDC_scope_city_stock` 提升后，整体 `new_applicant_share` 稳健上升。
2. 识别补强：`scope >= 2` 的事件研究前趋势较干净，事件后 1-2 年新进入份额上升。
3. 机制分解：新进入申请人数和新进入申请人专利数同步上升，不是既有主体专利下降造成的机械份额变化。
4. 风险说明：当前进入类型更多体现在个人申请人，企业/组织和发明授权口径还没打赢。
5. 异质性：企业在高算力技术领域的新进入数量上升，但份额不升，说明既有企业吸收更快。

一句话：

```text
这个题目前最能防守的是“算力服务覆盖扩大创新进入边界”，
企业层面只作为技术领域异质性和既有企业吸收更快的补充证据。
```
