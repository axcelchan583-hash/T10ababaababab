日期：2026-05-25

```text
城市算力基础设施提升是否扩大城市创新进入边界？
```

统一表述口径：

```text
理论对象：城市算力基础设施；
经验测度：IDC 经营许可覆盖强度 / IDC 服务覆盖强度；
变量名称：ln(1 + IDC_scope_city_stock_{c,t-1})。
```

## 当前判断

可以作为主线写：

```text
城市算力基础设施提升扩大城市创新生态的进入边界，
表现为新进入申请人份额上升。
```

暂时不能作为主因果结论写：

```text
IDC 明确导致城市创新头部再集中；
IDC 强化企业/高校/上市公司头部吸收能力。
IDC 稳健提高企业新进入份额。
```

原因是 HHI、Top10、基期 Top 和组织申请人口径结果对强固定效应、事件研究和类型分解较敏感。

## 机制与异质性补充

2026-05-25 已完成新进入机制拆分、主体类型拆分、城市基础异质性和快速质量稳健性。

结论：

- 主结果不是简单分母效应：新进入申请人数和新进入申请人专利数同步上升，既有主体专利没有显著下降；
- 新进入类型中，当前最稳的是个人申请人进入，企业/知识机构/组织申请人口径暂不显著；
- 发明申请公开口径支持主结果，发明授权口径方向为正但不显著；
- 基期创新能力、集中度和主体结构异质性暂不清楚。

## AJG3 升级检验第一轮

2026-05-25 已补一轮最小升级检验：

- `scope >= 2` 的现代 DID 复核：Borusyak-Jaravel-Spiess 和 Callaway-Sant'Anna 都显示事件后 1-4 年 `new_applicant_share` 显著上升，处理前三期不显著；
- 整体申请人城市 × 高算力技术领域 × 年份 DDD：高算力领域的新进入申请人数、新进入专利数和新进入份额相对上升；
- 时间安慰剂：未来 3 年、5 年 IDC 覆盖对 `new_applicant_share`、`ln1p_new_applicants`、`ln1p_new_patents` 均不显著；
- 组织申请人与发明授权口径仍不稳，不能把主结论升级为“企业/组织/高质量创新进入”。

当前判断：

```text
主线比上一版更能防守：城市算力基础设施扩大创新进入边界；
实证上用 IDC 服务覆盖强度测度。
但机制口径要谨慎：高算力领域额外更强，组织/企业进入和授权质量尚未打赢。
```

## 企业层面补充试验

2026-05-25 已完成企业申请人口径和城市 × 技术领域 × 年份 DDD 第一轮。

结论：

- 城市-年份企业 Y 不适合替代主 Y；
- 高算力技术领域中，企业新进入数量和新进入企业专利数量相对其他领域上升；
- 但新进入企业份额未上升，且事件 DDD 存在前趋势问题；
- 企业层面最多作为“高算力领域进入数量扩张，但既有企业吸收更强”的补充结果。

## 组会建议口径

建议组会中不要把企业层面改成主线，而是按以下顺序讲：

1. 主结果：`IDC_scope_city_stock` 提升后，整体 `new_applicant_share` 稳健上升。
2. 识别补强：`scope >= 2` 的事件研究前趋势较干净，事件后 1-2 年新进入份额上升。
3. 机制分解：新进入申请人数和新进入申请人专利数同步上升，不是既有主体专利下降造成的机械份额变化。
4. 风险说明：当前进入类型更多体现在个人申请人，企业/组织和发明授权口径还没打赢。
5. 异质性：企业在高算力技术领域的新进入数量上升，但份额不升，说明既有企业吸收更快。

一句话：

```text
这个题目前最能防守的是“算力服务覆盖扩大创新进入边界”，
企业层面只作为技术领域异质性和既有企业吸收更快的补充证据。
```
