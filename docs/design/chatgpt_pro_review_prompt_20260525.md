## 3. X：城市算力基础设施

主 X：

```text
ln(1 + IDC_scope_city_stock_{c,t-1})
```

构造方式：

- 来源为 IDC/电信业务经营许可数据；
- 只使用许可证业务覆盖范围中明确出现的城市；
- 按许可证颁发年份累计为城市-年份 IDC stock；
- 滞后一期进入回归。

本文的理论 X 是城市算力基础设施，经验测度是 IDC 经营许可覆盖强度 / IDC 服务覆盖强度。也就是说，论文标题和理论机制可以写“城市算力基础设施”，但变量解释必须说明它是以 IDC 经营许可覆盖构造的代理变量。

这个口径参考已有中文顶刊利用工信部电信业务经营许可证、筛选 IDC/B11 业务、从业务覆盖范围提取数据中心城市并累计到城市-年份的做法。

稳健性 X：

- 注册地 IDC stock；
- 覆盖范围优先 + 注册地 fallback 的 combined stock；
- 最近 5 年 IDC stock；
- 当年新增 IDC；
- 省份 IDC stock。

## 4. Y：创新进入边界

主 Y：

```text
new_applicant_share_{c,t}
```

定义：

```text
本城市本年首次出现的申请人的专利数 / 本城市本年总专利数
```

辅助 Y：

```text
ln(1 + new_applicants_{c,t})
```

这里的新进入不是企业新成立，也不是全国首次申请，而是申请人首次出现在该城市的专利申请人历史中。

补充结构 Y：

- `hhi`：城市年度申请人专利份额 HHI；
- `top10_share`：Top10 申请人份额；
- `base_top_share`：2008-2010 年基期 Top 申请人后续份额；
- `base_mid_inc_share`：基期非 Top 既有主体后续份额；
- 组织申请人口径：剔除个人后的 `org_hhi`、`org_top10_share`、`org_new_share`；
- Top 类型份额：企业、高校/学校、科研机构、医院、个人、政府、其他。

## 5. 识别设计

基准模型：

```text
Y_{c,t} = β ln(1 + IDC_scope_city_stock_{c,t-1})
        + μ_c
        + λ_t
        + ε_{c,t}
```

preferred specification：

```text
Y_{c,t} = β ln(1 + IDC_scope_city_stock_{c,t-1})
        + μ_c
        + Province × Year FE
        + BaselineCapacity × Year FE
        + ε_{c,t}
```

其中：

- `μ_c` 为城市固定效应；
- `Province × Year FE` 控制省份年度共同冲击；
- `BaselineCapacity × Year FE` 包括基期专利规模分组 × 年份和基期 Top10 分组 × 年份；
- 标准误按城市聚类。

请注意：这不是完美自然实验，而是连续处理强度城市面板固定效应设计，辅以事件研究。
已进一步补做 `scope >= 2` 的现代 DID 复核：Borusyak-Jaravel-Spiess 和 Callaway-Sant'Anna。

## 6. 事件研究

事件定义：

```text
城市 IDC_scope_stock 第一次达到 >= 1
城市 IDC_scope_stock 第一次达到 >= 2
城市 IDC_scope_stock 第一次达到 >= 3
城市 IDC_scope_stock 第一次达到 >= 5
```

事件窗口：

```text
<= -4, -3, -2, -1, 0, +1, +2, +3, >= +4
```

`-1` 为遗漏基准期。

处理组：

```text
首次达到阈值年份在 2012-2020 年的城市
```

对照组：

```text
从未达到该阈值的城市
```

当前最推荐阈值是 `scope >= 2`：

```text
66 个处理城市
275 个总城市
```

关键结果：

```text
scope >= 2，强固定效应规格：
前趋势联合检验 p = 0.765
事件后 +1 年 new_applicant_share 上升，p = 0.033
事件后 +2 年 new_applicant_share 上升，p = 0.084
```

因此事件研究支持“创新进入边界扩展”，但 HHI、Top10、base_top_share 的事件动态不稳定，不能支持“头部再集中”的强因果结论。

现代 DID 复核结果：

```text
BJS：new_applicant_share 处理前三期联合检验 p = 0.762；
BJS：事件后 +1、+2、+3、+4 年 new_applicant_share 均显著为正；
CSDID：事件后 +1、+2、+3、+4 年 new_applicant_share 均显著为正；
ln1p_new_applicants 与 ln1p_new_patents 在两套现代 DID 中也显示事件后上升。
```

## 7. 当前主要结果

主结果：

- `new_applicant_share` 在城市+年份 FE、省份×年份 FE、强固定效应、城市趋势等规格下均显著为正；
- `ln1p_new_applicants` 在强规格和城市趋势下为正；
- 分子/分母分解显示，`ln1p_new_applicants` 和新进入申请人专利数同步上升，既有主体专利没有显著下降，因此主结果不是简单分母效应；
- 剔除大城市、高专利量样本下，新进入份额仍较稳；
- 事件研究和现代 DID 支持 `scope >= 2` 后新进入份额上升。

结构性补充结果：

- 常规省份×年份 FE 下，`hhi/top10/base_top_share` 为正，`base_mid_inc_share` 为负；
- 加入基期能力/集中度 × 年份 FE 后，集中度和基期 Top 结果明显变弱；
- 事件研究中 HHI/Top10 动态不稳定。

Top 类型和组织口径：

- Top20 专利量中，企业和高校/学校是主要头部主体；
- IDC 没有稳定提高企业头部份额；
- IDC 没有稳定提高高校/科研头部份额；
- 基期 Top 企业/高校份额没有稳健上升；
- 剔除个人后，组织申请人 HHI/Top10 在强固定效应下消失；
- 组织申请人专利占城市总专利比例有下降迹象。

新进入类型拆分：

- 企业新进入份额、企业新进入数量、企业新进入专利数暂不显著；
- 高校/科研/医院等知识机构暂不显著；
- 个人新进入份额和个人新进入数量显著上升；
- 组织申请人口径暂不显著。

因此当前不能写：

```text
IDC 强化企业/高校/上市公司头部吸收能力。
IDC 稳健促进企业创新进入。
```

企业层面补充：

- 城市-年份企业 Y 较弱：`firm_new_share_total` 不显著，`ln1p_new_firm_patents` 不显著，`ln1p_new_firm_applicants` 只在高专利量城市中边际为正；
- 企业口径事件研究没有复现整体新进入申请人份额的清晰动态；
- 城市 × 技术领域 × 年份 DDD 显示，高算力技术领域的企业新进入数量和新进入企业专利数相对上升；
- 但高算力领域中新进入企业份额没有上升，连续强度 DDD 中反而为负；
- 事件 DDD 有处理后数量正信号，但前趋势不干净。

因此当前对企业层面的定位是：

```text
企业层面不替代主 Y；
可以作为技术领域异质性/补充结果：
高算力领域企业进入数量扩张，但既有企业吸收更快。
```

整体申请人技术领域 DDD：

- 已构造整体申请人城市 × 高算力技术领域 × 年份面板；
- 模型吸收 `city × year`、`city × HighCompute`、`HighCompute × year`；
- 高算力领域的新进入申请人数、新进入专利数和新进入份额相对上升；
- 低算力领域单独回归也为正，因此更准确机制是“普遍扩容 + 高算力领域额外增强”，不是“只影响高算力领域”。
