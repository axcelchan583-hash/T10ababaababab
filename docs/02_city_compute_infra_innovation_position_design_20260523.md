# 城市算力基础设施与上市公司创新优势重塑：实验设计草案

日期：2026-05-23

## 1. 当前判断

这个方向可以从原来的“城市数据/算力基础设施提升企业创新韧性”切换为：

> 城市算力基础设施作为公共型数字底座，是否降低城市创新进入门槛、扩展非上市主体创新空间，从而重塑上市公司在城市创新生态中的相对地位？

这一路线的好处是：此前“上市公司相对城市平均没有跑赢、甚至显著为负”的结果，不再只是坏结果，而可以被解释为城市创新生态扩容和创新优势再分配。

需要避免的表述：不要直接写成“算力基础设施抑制上市公司创新”。更稳的表述是“重塑上市公司创新相对地位”或“削弱上市公司的既有创新优势”。

## 2. 研究问题和核心假说

主问题：

> 城市算力基础设施建设是否降低上市公司在本地创新生态中的相对优势？

核心机制：

1. 算力基础设施降低数据处理、模型训练、云服务和数字研发的固定成本。
2. 基础设施具有公共性和平台性，不只服务上市公司，也服务非上市企业、创业企业、科研机构和数字服务商。
3. 城市整体创新被抬高，但上市公司未必比城市整体跑得更快。
4. 因此，上市公司的城市创新份额可能下降，其相对创新地位被重塑。

可检验假说：

- H1：城市算力基础设施建设提高城市整体创新产出。
- H2：城市算力基础设施建设降低上市公司在城市创新产出中的份额。
- H3：上述下降主要来自非上市主体、创业主体或科研机构创新扩张，而不是上市公司绝对创新萎缩。
- H4：在上市公司原有创新优势更强、城市创新资源更集中、或数字服务市场更活跃的地区，重塑效应更明显。

## 3. 解释变量 X

主 X：

- `idc_new`：城市 c 在年份 t 新获批的互联网数据中心业务许可证数量。
- `idc_stock`：截至年份 t，城市 c 累计获批的互联网数据中心业务许可证数量。
- 回归中优先使用 `ln1p_idc_stock`，并用 `ln1p_idc_new`、滞后一期 X、首次获批事件作为稳健性。

当前可用版本：

- 已有 51miit 镜像代理数据，能做探索性试跑。
- 正式论文最好换成工信部政务服务平台 B11 类 IDC 许可证原始数据，保留许可证编号、企业名称、批准年份、机房或业务覆盖城市。

不建议作为主 X：

- 2016 年“国家大数据综合试验区”虚拟变量可以做稳健性或补充政策冲击，但它覆盖面粗，和“算力基础设施”含义不如 IDC 许可证紧。

## 4. 被解释变量 Y

主 Y 应该从“创新韧性”切换到“创新相对地位”。

### 4.1 城市层面主 Y

`ListedShare_ct`：

> 城市 c 年份 t 内 A 股上市公司发明专利授权量之和 / 城市 c 年份 t 全部发明专利授权量

备选口径：

- 上市公司专利授权总量份额。
- 上市公司专利申请量份额。
- 上市公司发明专利授权份额，作为最核心口径。

这个 Y 最贴近“上市公司创新优势是否被削弱”。

### 4.2 企业层面主 Y

`RelPos_ict`：

> `ln(1 + 企业发明专利授权量) - ln(1 + 所在城市发明专利授权总量)`

或：

> `企业发明专利授权量 / 所在城市发明专利授权总量`

企业层面 Y 的优点是可以加企业固定效应和企业控制变量。缺点是比例变量容易受小城市、小分母影响，所以需要配合城市层面份额结果和分解检验。

### 4.3 分解结果

为了证明不是“上市公司创新被压制”，必须同时跑：

- 城市整体创新：`ln(1 + 城市发明专利授权总量)`
- 城市内上市公司创新总量：`ln(1 + 城市内上市公司发明专利授权总量)`
- 上市公司创新份额：`ListedShare_ct`

理想模式是：

- 城市整体创新显著上升；
- 上市公司绝对创新不下降，甚至上升；
- 但上市公司创新份额下降。

这个组合才能支撑“城市创新生态扩容导致上市公司相对优势被稀释”。

## 5. 现在已有数据

已经能做 2000-2024 的第一轮试跑：

- 企业-年份专利数据：上市公司专利申请、授权、发明授权。
- 城市-年份专利数据：城市专利申请、授权、发明授权。
- 企业注册地/城市归属：省份、城市、城市代码，但正式合并时应优先用“省份+城市”字符串，避免当前 IDC 代理数据中的城市代码污染问题。
- IDC 代理数据：城市-年份 `idc_new`、`idc_stock`。
- 企业财务控制变量：`Size`、`Lev`、`ROA`、`Growth` 等已有到本地中间表。

因此，最小试跑不需要等新数据。可以先用现有 2000-2024 数据构造上市公司城市创新份额和企业相对创新地位。

最低字段：

- 专利号

### 6.2 强烈建议补

建议字段：

- 财政科技支出、教育支出

5. 企业控制变量完整版

建议字段：

### 6.3 可选增强

6. 新企业进入和创新创业数据

用途：机制检验“基础设施降低创新进入门槛”。

可选口径：

- 高新技术企业数量
- 科技型中小企业数量
- 风险投资事件数量
- 数字服务企业数量

7. 人才和数字服务市场数据

用途：解释为什么上市公司份额下降。

可选口径：

- 城市 AI/云计算/软件招聘需求
- 数字服务商数量
- 云服务采购或政府数字采购数据

## 7. 基准模型

### 7.1 城市层面份额模型

城市-年份层面：

`ListedShare_ct = beta * IDC_ct + CityFE + YearFE + CityControls_ct + error_ct`

预期：

- `beta < 0`

这个模型最直接回答：算力基础设施是否降低上市公司在城市创新中的份额。

### 7.2 城市创新分解模型

分别估计：

`ln(1 + CityPatent_ct) = beta1 * IDC_ct + FE + controls + error`

`ln(1 + ListedPatent_ct) = beta2 * IDC_ct + FE + controls + error`

`ListedShare_ct = beta3 * IDC_ct + FE + controls + error`

理想证据链：

- `beta1 > 0`
- `beta2 >= 0` 或不显著为负
- `beta3 < 0`

这说明不是上市公司创新被打压，而是城市整体创新扩张更快。

### 7.3 企业层面相对地位模型

企业-年份层面：

`RelPos_ict = beta * IDC_ct + FirmFE + YearFE + FirmControls_it + CityControls_ct + error_ict`

预期：

- `beta < 0`

注意：

- 聚类应放在城市或省份-城市层面。
- 不应使用城市-年份固定效应，因为 X 本身是城市-年份变量。
- 可以加入行业-年份固定效应，控制行业创新周期。

## 8. 识别和稳健性

主要风险：

1. IDC 建设不是随机的，可能落在本来创新增长快的城市。
2. 份额类 Y 可能受小分母影响。
3. 城市行政区划和城市名称匹配可能造成噪声。
4. 若上市公司注册地址不等于创新活动地，企业城市归属存在测量误差。

处理方式：

- 使用城市固定效应和年份固定效应。
- 加入城市层面经济、人口、产业和科技资源控制。
- 加入城市线性趋势或省份-年份固定效应做稳健性。
- 用首次 IDC 获批年份做事件研究，检查前趋势。
- 排除城市专利分母过小的城市-年份。
- 分别使用申请、授权、发明授权口径。
- 使用 `ln(1 + firm patent) - ln(1 + city patent)` 替代简单比例。
- 用 2016 年国家大数据综合试验区作为替代 X。

## 9. 明天优先试跑清单

第一步：用现有数据构造城市-年份上市公司创新份额。

- 分母：城市发明专利授权总量。
- 分子：同城 A 股上市公司发明专利授权量之和。
- 样本：2008-2024，另做 2012-2022。

第二步：跑三组分解。

- IDC -> 城市整体发明授权。
- IDC -> 城市内上市公司发明授权。
- IDC -> 上市公司发明授权份额。

第三步：跑企业层面相对地位。

- Y1：`ln(1 + 企业发明授权) - ln(1 + 城市发明授权)`
- Y2：`企业发明授权 / 城市发明授权`

第四步：画事件图。

- 以城市首次 IDC 许可证获批年份为事件年。
- 看上市公司创新份额在获批前后是否下降。

第五步：做机制初筛。

- 如果暂时没有全量非上市专利微观数据，先用 `城市总专利 - 上市公司专利合计` 得到非上市/非 A 股创新近似量。
- 若 IDC 提高这个近似量，同时降低上市份额，机制初步成立。

## 10. 继续/放弃标准

建议继续的结果组合：

- IDC 显著提高城市整体创新；
- IDC 不显著降低上市公司绝对创新；
- IDC 显著降低上市公司创新份额或企业相对创新地位；
- 事件研究前趋势没有明显问题。

建议谨慎或放弃的结果组合：

- 城市整体创新也不升；
- 份额下降只出现在小分母城市；
- 结果完全由直辖市或少数超大城市驱动；
- 正式 IDC 数据替换代理数据后结果消失；
- 非上市创新近似量没有增加。

## 11. 当前一句话版本

本文不再把城市算力基础设施视为单纯提升上市公司创新的外部条件，而是将其理解为城市创新生态的公共型底座。算力基础设施可能降低创新活动的进入门槛，使非上市主体和新进入主体更快扩张，进而削弱上市公司在本地创新产出中的既有优势，重塑城市内部的创新相对地位。

## 12. 现有专利数据可行性检查

检查日期：2026-05-23

现有专利数据可以先做“第二步”，即：

> 城市创新增量中，是否是非 A 股/其他主体增长更快，从而降低上市公司创新份额？

当前可以直接构造：

- 城市总创新：地级市专利申请、授权、发明授权。
- A 股上市公司创新：同一城市-年份内 A 股上市公司专利申请、授权、发明授权合计。
- 非 A 股/其他主体创新近似量：城市总创新 - A 股上市公司创新合计。
- 上市公司创新份额：A 股上市公司创新合计 / 城市总创新。

已生成完整城市-年份分解表：

`outputs/city_listed_nonlisted_patent_decomposition_full_2000_2024.csv`

数据质量检查结果：

- 完整城市-年份面板：2000-2024 年，298 个城市，7450 个城市-年份。
- 有 1548 个城市-年份没有 A 股上市公司，已将上市公司专利合计补为 0。
- 同一省份-城市-年份内，城市专利总量在企业表中完全一致。
- 企业-年份没有重复记录。
- 少量城市-年份存在 A 股上市公司合计大于城市总量的问题：
  - 专利申请：12 / 7450。
  - 专利授权：13 / 7450。
  - 发明授权：61 / 7450。

正式回归处理建议：

- 主口径使用发明专利授权份额。
- 剔除 `非A股近似量 < 0` 的城市-年份，或将份额 winsorize 到 `[0, 1]`。
- 同时报告专利申请、授权、发明授权三种口径。
- 第一轮可以只用“非 A 股/其他主体创新近似量”，后续若结果好，再补全量申请人微观数据来区分非上市企业、高校、科研院所。

因此，第一轮试跑不需要等待新专利数据；现有数据已经能验证“上市公司相对创新份额是否下降，以及非 A 股近似创新是否增长更快”。

## 13. Pro 诊断后的路线修订

更新时间：2026-05-23

根据 ChatGPT Pro 的诊断和现有回归结果，本文不宜继续以“上市公司创新优势被削弱”为单向主线。更合适的研究问题是：

> 城市数字/算力基础设施建设会让城市创新主体结构更加分散，还是进一步强化头部主体的创新集中？

这一路线的核心变化是：

- 不再预设上市公司一定输；
- 不再用 `B/T` 或 `ln(C)-ln(B)` 作为主 Y；
- 不再把 `C = 城市总创新 - A 股上市公司创新合计` 解释成清晰的“非上市主体创新”；
- 改为使用全量专利申请人微观数据，直接测量城市内部创新主体结构。

### 13.1 新主 Y

城市-年份层面：

`Applicant_HHI_ct`

> 城市 c 年份 t 内，各申请人专利份额平方和。

配套变量：

- `Top1_share_ct`：最大申请人专利份额。
- `Top5_share_ct`：前 5 大申请人专利份额。
- `Top10_share_ct`：前 10 大申请人专利份额。
- `Effective_applicants_ct = 1 / HHI_ct`。
- `Active_applicants_ct`：当年活跃专利申请人数量。
- `New_applicants_ct`：当年首次在该城市出现的专利申请人数量。
- `New_applicant_patent_share_ct`：新进入申请人专利份额。

上市公司变量降级为第二层结果：

- `Ashare_top1_ct`：城市年度第一大申请人是否为 A 股上市公司或其集团主体。
- `Ashare_top5_count_ct / 5`。
- `Ashare_top10_count_ct / 10`。
- 单个上市公司在本城市所有申请人中的排名或百分位。

### 13.2 新解释框架

如果结果显示：

```text
IDC -> HHI 下降
IDC -> Top5 share 下降
IDC -> Active / New applicants 上升
```

解释为：

> 算力/数字基础设施降低创新进入门槛，扩大城市创新生态，推动创新主体扩散。

如果结果显示：

```text
IDC -> HHI 上升
IDC -> Top5 share 上升
IDC -> A 股或头部主体 Top10 占比上升
```

解释为：

> 算力/数字基础设施与既有研发能力、数据资产、资金能力和组织吸收能力互补，强化头部主体创新优势，推动创新再集中。

这比“上市公司优势下降”更稳，因为它允许数据回答“扩散还是再集中”。

### 13.3 明天优先 smoke test

第一步：从大型专利微观数据中抽取最小字段。

- 专利号；
- 申请人或权利人名称；
- 申请人城市；
- 申请年份或授权年份；
- 专利类型。

第二步：聚合到申请人-城市-年份。

第三步：构造城市-年份集中度。

- HHI；
- Top1/Top5/Top10 share；
- active applicants；
- new applicants。

第四步：合并 IDC 代理 X。

- `ln1p_idc_stock`；
- `ln1p_idc_new`；
- 滞后一期。

第五步：先跑最小模型。

`Y_ct = beta * IDC_ct + CityFE + YearFE + error_ct`

### 13.4 Go / Pivot / No-Go

Go：

- HHI 或 Top5 share 显著下降；
- active applicants 或 new applicants 显著上升；
- 城市总创新增加或至少不下降。

Pivot：

- HHI 或 Top5 share 显著上升；
- A 股或头部主体在 Top10 中占比上升；
- 上市公司或头部申请人响应明显更强。

这时题目改为：

> 城市算力基础设施与创新再集中。

No-Go：

- HHI、Top share、active applicants、new applicants 全部不显著；
- 只有 `B/T` 或 `ln(C)-ln(B)` 有结果；
- 只有政府工作报告词频有结果，但城市创新总量为负。

### 13.5 当前状态

当前已有低配城市份额结果只能作为诊断材料，不能作为主结果。下一轮是否继续，取决于全量申请人集中度 smoke test。
