# 企业创新韧性 Y 构造方案

## 1. 公开数据包的构造

本次检查的数据包为：

`/Users/mac/computerscience/第三方资料/90_临时下载待归档/上市公司创新韧性数据（2000-2024年）`

数据包包含成品数据、原始企业专利数据、原始城市专利数据、两篇参考文献和 Stata 计算代码。成品数据有 68,851 个企业-年度观测，年份实际为 2000-2024 年，覆盖 5,732 家上市公司。

公开数据给出四个指标：

| 指标 | 主要口径 | 参照文献 |
|---|---|---|
| 企业创新韧性1 | 企业发明专利授权量相对城市发明专利授权变化的超额反弹 | 黄贤环、温滟琳（2025） |
| 企业创新韧性2 | 企业专利申请量相对城市专利申请变化的超额反弹 | 卢正文、许康（2024） |
| 企业创新韧性3 | 企业专利授权量相对城市专利授权变化的超额反弹 | 卢正文、许康（2024） |
| 企业创新韧性4 | 企业专利申请量相对行业专利申请变化的超额反弹 | 卢正文、许康（2024）的扩展口径 |

核心思想是 Martin 式相对韧性：

```text
IR_it = (实际创新变化_it - 基准预测创新变化_it) / |基准预测创新变化_it|
```

公开代码中的具体实现大致为：

```stata
城市专利增长率 = (城市专利_t - 城市专利_t-1) / 城市专利_t-1
企业专利变化 = 企业专利_t - 企业专利_t-1
企业创新韧性 = (企业专利变化 - 城市专利增长率 * 企业专利_t) / abs(城市专利增长率 * 企业专利_t)
```

行业版本使用行业专利申请量的绝对变化，而不是增长率。

## 2. 公开口径的主要问题

1. 当前数据包没有 2025 年数据。虽然两个原始 Excel 的工作表名写作 `1949-2026`，但实际企业专利数据和城市专利数据都只到 2024 年。本机另有的国泰安“上市公司发明申请专利细分分类号”数据也只到 2024 年。

2. 公开代码和文献公式不完全一致。黄贤环、温滟琳（2025）的公式是用企业上一期专利量乘以区域增长率来得到预测变化，但公开代码里使用的是当期企业专利量。

3. 分母很不稳定。若城市或行业专利增长率接近 0，指标会出现极端值。成品数据中，企业创新韧性1、2、3 的 1% 和 99% 分位跨度很大。

4. 企业创新韧性4的问题更明显。公开代码先计算行业专利申请量的绝对变化，再乘以企业当期专利申请总量，导致指标中位数接近 -1，解释含义较弱。

5. 这些指标衡量的是一般创新韧性，不是数字创新韧性。它们没有区分普通专利、发明专利、数字技术专利、AI/数据相关专利。

## 3. 我们更适合使用的新口径

如果题目是“城市数据基础设施对企业创新韧性的影响”，建议不要直接使用公开数据包的四个指标。更适合作主 Y 的是：

**企业数字创新韧性**

即企业数字技术创新产出相对于同业、同城或同城同行基准的超额维持与恢复能力。

推荐主指标：

```text
FirmDigIR_it =
  (ΔDigInvPatent_it - ExpectedΔDigInvPatent_it)
  / (1 + |ExpectedΔDigInvPatent_it|)
```

其中：

```text
ΔDigInvPatent_it = DigInvPatent_it - DigInvPatent_i,t-1
ExpectedΔDigInvPatent_it = DigInvPatent_i,t-1 * g_peer,t
```

`g_peer,t` 使用 leave-one-out 的同业或同城同行数字发明专利增长率：

```text
g_peer,t =
  (Σ DigInvPatent_peer,t - Σ DigInvPatent_peer,t-1)
  / (1 + Σ DigInvPatent_peer,t-1)
```

这里 `peer` 不包含企业自身，避免大企业把自己同时放进基准组。

## 4. 这个新口径和公开数据的区别

1. 公开数据是一般专利韧性；我们是数字创新韧性，更贴合城市数据基础设施。

2. 公开数据主要用城市基准；我们可以用同业、同城同行、或城市-行业 leave-one-out 基准。

3. 公开数据使用当期企业专利量参与预测；我们使用滞后企业专利量，更符合文献公式和反事实预测逻辑。

4. 公开数据分母容易爆炸；我们用 `1 + |ExpectedΔ|` 稳定分母。

5. 公开数据只给 2000-2024；我们可以在补齐 2025 年企业专利和城市/行业专利后自然扩展到 2025。

## 5. 2025 年能不能做

当前本地材料不能直接做真实 2025 年，因为缺少 2025 年企业专利和城市专利原始数据。

要做 2025 年，至少需要补三类数据：

1. 企业-年度专利数据：上市公司 2025 年专利申请、授权、发明申请、发明授权，最好有 IPC 分类。
2. 地级市-年度专利数据：2025 年城市专利申请、授权、发明授权，若做数字创新韧性则也要有城市数字专利。
3. 企业所在地和行业代码：用于匹配城市、行业和 city-industry peer benchmark。

若能补到 IPC 分类，则优先构造：

```text
Y1 = 企业数字发明申请韧性
Y2 = 企业数字专利申请韧性
Y3 = 企业发明授权韧性
Y4 = 企业数字专利知识宽度韧性
```

其中 Y1 应作为主指标，Y2-Y4 做稳健性。

## 6. 对选题的判断

这个 Y 是可以继续做的，但要避免直接使用公开的“企业创新韧性1-4”。最干净的做法是自己构造“企业数字创新韧性”，把理论落在“数据基础设施增强企业在数字创新系统中的抗冲击、恢复和转化能力”上。

如果暂时拿不到 2025 年专利数据，可以先用 2000-2024 年重构一个不同于公开数据的版本，验证口径、分布和回归方向；等 2025 年专利数据补齐后再扩展。
